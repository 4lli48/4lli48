## Featured projects

<details open>
<summary><strong>SentinelAI: Governed transaction risk review</strong></summary>

SentinelAI is an Arabic-first hackathon prototype for explainable transfer-risk review. It combines a deterministic policy engine, a behaviour signal, regulatory RAG, and a constrained AI recommendation into a reviewable composite decision.

| Category | Details |
| --- | --- |
| Stack | React, TypeScript, Vite, Express, tRPC, Supabase, Ollama, Vitest |
| Architecture | Frozen decision snapshots, rule engine, behavioural signal, grounded AI recommendation, and composite guardrails |
| Local AI | Ollama with Qwen3 for local presentation mode, without silent cloud fallback |
| Documentation | Architecture notes, committee runbook, local setup, and test commands |
| Repository | [sentinelai-hackathon-demo](https://github.com/4lli48/sentinelai-hackathon-demo) |

</details>

<details>
<summary><strong>Hail Culture House: technology inventory management</strong></summary>

A bilingual inventory management application for technology devices. It includes authentication, protected routes, device CRUD workflows, categories, reports, Arabic and English interface support, RTL and LTR layouts, and light and dark themes.

| Category | Details |
